# Audit rubric and evidence rules

Defined before scoring or UI edits. Each category is judged against the same observable checks before and after. Full credit requires passing the checks in the evaluated environment; untested native-device and assistive-technology behavior receives explicit deductions. Scores are design heuristics, not user-satisfaction measurements.

| Category                     | Max | Observable criteria                                                                                                                                                                                                                                        |
| ---------------------------- | --: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Guest/host journey clarity   |  25 | New vs returning guest distinction; optional avatar; correct current/editing round; understandable next host action; lock/results transition; complete event without a display                                                                             |
| Mobile interaction           |  25 | 320/390px guest and host fit; 200% text; one-hand entry hierarchy and optional clutter; all rating endpoints/decimals with no default; touch drawing/scrolling; repeated-action safety. Reserve deductions for untested native keyboard/viewport behavior. |
| Feedback/validation/recovery |  20 | Blank vs confirmed saves; delayed/failed saves; retained drafts and conflict choice; actionable duplicates/missing answers; submitted-to-draft explanation; stale/offline state; PIN and expired host recovery                                             |
| Results comprehension        |  15 | Guess vs reveal stage; follow vs browsing and accessible return; no eligible ratings vs zero; exclusions/ties/incomplete explanations; distance-readable display; private notes and future-answer restrictions                                             |
| Accessibility/consistency    |  15 | WCAG 2.2 AA automated scan, labels/headings/focus/status/keyboard checks, contrast and non-color signals, reduced motion, enlarged text and narrow reflow. Reserve deductions for untested physical-device/screen-reader behavior.                         |

Severity: P0 participation/work loss/secrecy/destructive error; P1 likely event-night confusion or delay; P2 polish or uncommon friction. Score changes must reference screenshots, interaction assertions or source findings; do not award points for merely adding code. Target >=95, no unresolved P0, and passing saving/submission/scoring/lock/secrecy regression plus complete guest-host walkthrough. At most five passes; report any unmet acceptance honestly.
